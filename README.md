# TokenPlane install access

TokenPlane is pre-release and its repository is private. To install it on your own
machine, open an issue here with the **Request an install invitation** form. We invite the
GitHub account that opened the issue to the private repository; the install page and the
download are there.

TokenPlane runs entirely on your machine. Nothing about your usage leaves it. What the
product does is at https://tokenplane.io, and a read-only demo over synthetic data is at
https://demo.tokenplane.io.
